# ⚛️ Orbital — Interactive Periodic Table & Atomic Trends Visualizer

An advanced, interactive periodic table web application designed for chemistry students, educators, and science enthusiasts. Featuring all 118 chemical elements, real-time atomic trend heatmaps, animated Bohr atomic orbits, quantum orbital filling diagrams (Aufbau principle), holographic specimen characterizations, side-by-side element comparison with bond character analysis, chemistry quiz challenge, and full multilingual localization.

## ✨ Key Features
- **Modern Rocanville Dashboard UI**: Clean light-theme interface with 3-column layout, pill/chip system, and typography hierarchy.
- **Floating Frosted Holographic Tooltip**: 80ms hover intent, smart auto-flip, zero layout shift.
- **Multilingual Localization (i18n)**: 6 languages supported:
  - English (`en`)
  - Hindi (`hi`) — हिन्दी 🇮🇳
  - Urdu (`ur`) — اردو 🇮🇳
  - Tamil (`ta`) — தமிழ் 🇮🇳
  - Telugu (`te`) — తెలుగు 🇮🇳
  - Marathi (`mr`) — मराठी 🇮🇳
- **Thermal Scrubber**: Adjust temperature from 0 K (Absolute Zero) to 6000 K (Solar Photosphere) to watch elements transition across Solid, Liquid, and Gas phases.
- **Atomic Trends Periodicity Curve**: Visualize electronegativity, atomic radius, ionization energy, electron affinity, and melting points across periods.
- **Side-by-Side Element Comparison Tool**: Predict chemical bond polarity (Pauling scale $\Delta\chi$) and compare Bohr shells side-by-side.
- **Chemistry Trends Challenge**: Interactive chemistry quiz with instant feedback and deep scientific explanations.
- **Full Quantum & Physical Specimen Modal**:
  - Macroscopic physical specimen photographs & characterizations.
  - Interactive Canvas Bohr atomic orbital animation.
  - Aufbau principle orbital box diagrams (Hund's Rule & Pauli Exclusion Principle).
  - Audio pronunciation of element names.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/VASEEM0044/Orbital-Interactive-Periodic-Table.git
   cd Orbital-Interactive-Periodic-Table
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
